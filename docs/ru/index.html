Начало

Введение

Oktopus — форвард-прокси с веб-кабинетом. Разделы документации совпадают со страницами кабинета (/manage/…).

Обзор

  • Прокси — контроль HTTP/HTTPS по политикам.
  • Кабинет — те же пункты меню, что в ManageSidebar.
  • Карта для агентов — docs/DOC_MAP.md, docs/manifest.json.

Языки

Две копии сайта: русская и английская (docs/ru/, docs/en/).

Начало

Быстрый старт

Клонирование и запуск стека. Linux — docker-compose.yml, Windows — docker-compose.desktop.yml.

Клонирование

shell
git clone https://github.com/Camyil-89/oktopus.git
cd oktopus

Запуск

shell
docker compose up -d

Разработка

shell
go run ./cmd serve

UI: web/, npm run dev.
