Начало

Введение

Oktopus — форвард-прокси с веб-кабинетом для управления правилами доступа, пользователями и журналом соединений. Документация в разработке; здесь — краткий обзор и первые шаги.

Что это

  • Прокси — HTTP/HTTPS с проверкой политик до выхода в интернет.
  • Кабинет — настройка ACL, пользователей, прокси-правил и отчётов.
  • Хранилище — PostgreSQL для конфигурации; ClickHouse для аналитики журнала (в полном стеке).

Репозиторий

Исходники и docker-compose.yml для on-prem развёртывания — в GitHub. Подробные разделы (конфигурация, API, CLI) появятся в боковом меню по мере наполнения.

Совет

Локально откройте docs/index.html в браузере или включите GitHub Pages с папкой /docs — см. настройки репозитория.

Начало

Быстрый старт

Минимальный путь: клонировать репозиторий и поднять стек через Docker Compose (Linux). На Windows для полного стека смотрите docker-compose.desktop.yml.

1. Клонирование

shell
git clone https://github.com/Camyil-89/oktopus.git
cd oktopus

2. Переменные окружения

Скопируйте пример .env из скриптов развёртывания в корне проекта (см. scripts/stack-up.sh или stack-up.bat) и задайте пароли БД.

3. Запуск

shell
docker compose up -d

Разработка без Docker

shell
go run ./cmd serve

UI собирается отдельно в каталоге web/ (npm run dev). Точные порты и URL — в комментариях к docker-compose.yml.
