Getting started

Introduction

Oktopus is a forward proxy with a web console. Documentation sections mirror console routes (/manage/…).

Overview

  • Proxy — HTTP/HTTPS access control by policy.
  • Console — same menu items as ManageSidebar.
  • Agent map — docs/DOC_MAP.md, docs/manifest.json.

Languages

Two static sites: Russian and English (docs/ru/, docs/en/).

Getting started

Quick start

Clone and run the stack. Linux — docker-compose.yml, Windows — docker-compose.desktop.yml.

Clone

shell
git clone https://github.com/Camyil-89/oktopus.git
cd oktopus

Run

shell
docker compose up -d

Development

shell
go run ./cmd serve

UI: web/, npm run dev.
