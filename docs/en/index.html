Development

Developers

Oktopus — forward proxy and control panel (Go + Next.js). Locally: run dependencies in Docker, API/proxy and UI from source on the host. Production Docker — Deployment.

Control panel docs

Control panel sections describe the UI for administrators. This page is for working in the repository.

Dependencies (Docker)

From the repo root, start the dev stack: PostgreSQL, ClickHouse, OpenLDAP, and a small nginx for load tests. LDAP accounts and ports are documented in docker-compose.dev.yml.

shell
docker compose -f docker-compose.dev.yml up -d

Copy .env.example to .env at the repo root (defaults match dev-compose: Postgres 5434, ClickHouse native 9054, HTTP 8177).

Backend and frontend

  1. API and proxy — from the repo root with .env loaded: go run ./cmd serve. Default API listen: 127.0.0.1:8000 (OKTOPUS_API_LISTEN).
  2. UI (Next.js) — web/: npm install, then npm run dev (typically http://localhost:3000). Set NEXT_PUBLIC_API_URL=http://localhost:8000 in web/.env.local if the browser cannot reach the API (see .env.example).
  3. Open the UI, sign in (first DB bootstrap uses OKTOPUS_ADMIN_* from .env, default admin / admin).

Documentation

After product changes, check docs/DOC_MAP.md and run node docs/build.mjs.
