Proxy instances

Each instance has its own listen address, ACL, inspect rules, and settings (tunnel / MITM, CA, auth). Named ACL Lists are shared across instances. Create the first one with Add instance (unique name, free listen). Manage an instance from the sidebar: statistics, rules, settings, instance access log.

How to use it

After sign-in, check fleet RUNNING/STOPPED, ACL build, traffic, and runtime; data refreshes about every 3s. Startup errors show in a warning — fix instance settings or server logs.
