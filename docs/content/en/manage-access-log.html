How to use

Set time range and filters, open a row for details (rule, latency, inspect). Use purge actions if your role allows removing old entries.

Instances

The global log includes an instance column and filter. The Access log sub-item under an instance name in the sidebar opens the same UI pre-scoped to that listen.
