Basics

  • Listen — where clients connect for this instance.
  • Mode (tunnel / MITM) — tunnel checks destination via SNI; MITM decrypts HTTPS for URL ACL and inspect (requires CA on clients).
  • CA — generate or upload the MITM root certificate.
  • Auth — optional proxy authentication (static users or LDAP).

Block pages

Configure HTML for ACL deny and gateway errors so users see a clear message instead of a dropped connection.

Instance lifecycle

Rename the instance, change listen when the port is free, disable with enabled, or delete the instance (ACL and inspect config removed; access log rows kept). Create new instances on Home.

After changes

Save and confirm RUNNING on instance statistics or Home. For MITM, distribute the CA to clients.
