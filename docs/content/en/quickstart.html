Deployment

Run Oktopus in Docker: the stack script writes .env, starts Compose, and prints the control panel URL and admin credentials.

Requirements

  • Git and Docker Compose (docker compose).
  • Windows: Docker Desktop and docker-compose.desktop.yml. Linux: root docker-compose.yml.

Clone

shell
git clone https://github.com/Camyil-89/oktopus.git
cd oktopus

Linux and macOS

scripts/stack-up.sh prompts for API host and port (or set OKTOPUS_API_HOST / OKTOPUS_API_PORT), regenerates .env, then runs docker compose -f docker-compose.yml up --build -d.

bash
chmod +x scripts/stack-up.sh
./scripts/stack-up.sh

Env only (e.g. Portainer): ./scripts/stack-up.sh --write-env-only.

Windows

scripts\stack-up.bat uses docker-compose.desktop.yml. From the repo root:

cmd
scripts\stack-up.bat

Env only: scripts\stack-up.bat --write-env-only. OKTOPUS_API_HOST / OKTOPUS_API_PORT skip prompts.

After startup

  1. The script prints UI URL, admin login, and password from .env.
  2. Sign in and confirm the proxy is RUNNING on Home.
  3. Configure listen port and mode under Proxy settings.

Re-running the script recreates .env but keeps DB passwords when Docker volumes already exist.
