Навигация

В боковом меню при выбранном инстансе доступны: Статистика (эта страница), правила прокси, настройки, журнал доступа по инстансу. Общий журнал по всем listen — в пункте «Журнал доступа» верхнего уровня.

Нет данных runtime

Если инстанс только создан, может отображаться сообщение, что статус появится после запуска fleet. Проверьте, что процесс прокси на сервере запущен и listen свободен.
