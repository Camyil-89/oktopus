Разработчикам

Oktopus — корпоративный прокси и веб-панель (Go + Next.js). Локально: зависимости в Docker, API/прокси и UI — из исходников на хосте. Продакшен в Docker — Развёртывание.

Документация по панели

Разделы Панель управления описывают интерфейс для операторов. Эта страница — для разработки в репозитории.

Зависимости (Docker)

Из корня репозитория поднимите dev-стек: PostgreSQL, ClickHouse, OpenLDAP и вспомогательный nginx для нагрузочных тестов. Подробности и учётки LDAP — в комментариях в файле docker-compose.dev.yml.

shell
docker compose -f docker-compose.dev.yml up -d

Скопируйте .env.example в .env в корне (значения уже рассчитаны на порты из dev-compose: Postgres 5434, ClickHouse native 9054, HTTP 8177).

Бэкенд и фронтенд

  1. API и прокси — из корня репозитория, с загруженным .env: go run ./cmd serve. По умолчанию HTTP API слушает 127.0.0.1:8000 (см. OKTOPUS_API_LISTEN).
  2. Панель (Next.js) — каталог web/: npm install, затем npm run dev (обычно http://localhost:3000). В web/.env.local укажите NEXT_PUBLIC_API_URL=http://localhost:8000, если браузер не ходит в API (см. комментарии в .env.example).
  3. Откройте UI в браузере, войдите (при первом bootstrap — учётка из OKTOPUS_ADMIN_* в .env, по умолчанию admin / admin).
