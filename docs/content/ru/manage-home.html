Прокси-инстансы

Каждый инстанс — отдельный listen, свои ACL, инспекция и настройки (tunnel / MITM, CA, авторизация). Именованные Lists для ACL общие между инстансами. Создайте первый инстанс кнопкой Добавить инстанс: укажите имя и адрес прослушивания. Имя должно быть уникальным; listen не должен пересекаться с другим инстансом.

Управление инстансом — через пункт с его именем в боковом меню: статистика, правила, настройки, журнал доступа по этому listen.

Как пользоваться

После входа откройте главную: сводный RUNNING/STOPPED, сборка ACL по fleet, трафик и runtime. Данные обновляются каждые ~3 с. Если инстанс не стартует — предупреждение с текстом ошибки; проверьте настройки инстанса и логи сервера.
